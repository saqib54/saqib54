## 🐍 Contribution Snake

<p align="center">
  <img src="https://raw.githubusercontent.com/saqib54/saqib54/output/github-contribution-grid-snake-dark.svg" alt="snake animation"/>
</p>

**Setup (ek hi baar karna hai):**
1. `saqib54/saqib54` repo mein `.github/workflows/` folder banao
2. Uss mein `snake.yml` file daal do (maine bana ke di hai — download ho jayegi)
3. Repo → **Settings → Actions → General → Workflow permissions** → "Read and write permissions" select karo
4. Repo → **Actions** tab → `Generate Snake Animation` workflow → **Run workflow** (manually ek dafa chala do)
5. Woh khud `output` branch bana ke SVG generate kar dega, aur upar wali image automatically render hone lag jayegi
